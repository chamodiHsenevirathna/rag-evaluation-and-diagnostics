# AI assistance in this project

This project was developed with substantial assistance from AI coding assistants. The assistants drafted and edited source code, tests, experiment and analysis scripts, documentation and figures under the direction of the project owner. In addition:

* All evaluation datasets (the document corpus, the 40-case evaluation set, the 100-scenario development set and the 120-scenario fresh validation set) were written by AI assistants, one author context per set, **without human review** of the ground truth.
* The independent methodology review, the dashboard QA, the reproducibility check and the ownership and licensing review were performed by AI assistants, not by independent human reviewers. The licensing review is not legal advice.
* The statistical analyses were run by the project's own code and re-checked by AI assistants; no human statistician has reviewed them.
* The write-up in this release (README and documents) was drafted with AI assistance from the project's stored results; numbers were checked against those stored result files.

The project owner is responsible for the content. This release does not itemise which parts the owner personally wrote, reviewed or ran, so no part should be assumed to have had human review unless it says so above.
